# AI

Repositório centralizado para ferramentas, workflows e recursos de IA utilizados na rotina de trabalho.

## Estrutura

```
AI/
├── tools/        # Ferramentas e integrações de IA
├── workflows/    # Definições de workflows automatizados
├── prompts/      # Templates e bibliotecas de prompts
├── scripts/      # Scripts utilitários
└── docs/         # Documentação
```

## Começando

Cada diretório possui seu próprio `README.md` explicando os recursos disponíveis.

## Contribuindo

1. Crie um branch a partir de `main`
2. Faça suas alterações
3. Abra um Pull Request
