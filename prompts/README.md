# Prompts

A reusable library of prompt templates organized by use case.

## Structure

```
prompts/
├── README.md
└── templates/          # General-purpose prompt templates
```

## Format

Prompts are stored as Markdown files (`.md`). Each file should include:

- **Title** — What the prompt does
- **Use case** — When to use it
- **Variables** — Placeholders like `{{input}}` that you fill in
- **Prompt** — The actual prompt text
