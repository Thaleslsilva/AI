# Configs

Configuration templates and settings for AI tools and integrations.

> **Important:** Never commit real API keys or secrets. Use `.env.example` as a template and keep your actual `.env` file local (it is gitignored).

## Files

| File | Purpose |
|------|---------|
| `.env.example` | Template for environment variables (API keys, endpoints) |

## Usage

1. Copy `.env.example` to `.env` in the project root or tool directory.
2. Fill in your actual values.
3. Your `.env` file is gitignored and will not be committed.
