# Prompts

Biblioteca de templates de prompts reutilizáveis.

## O que vai aqui

- Templates de prompts por caso de uso
- System prompts para assistentes customizados
- Prompts de análise, resumo, geração de conteúdo, etc.

## Estrutura sugerida

```
prompts/
├── templates/    # Templates genéricos por categoria
├── system/       # System prompts para agentes/assistentes
└── examples/     # Exemplos de uso e outputs
```

## Formato

Salve prompts em arquivos `.md` ou `.txt` com uma breve descrição no topo de cada arquivo.
