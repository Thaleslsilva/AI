# Tools

Ferramentas e integrações com APIs e serviços de IA.

## O que vai aqui

- Clientes e wrappers de APIs (OpenAI, Anthropic, Gemini, etc.)
- Integrações com ferramentas externas
- Utilitários de processamento de texto/dados com IA

## Estrutura sugerida

```
tools/
├── openai/       # Integrações com OpenAI
├── anthropic/    # Integrações com Anthropic / Claude
├── local/        # Modelos locais (Ollama, LM Studio, etc.)
└── utils/        # Utilitários gerais
```
