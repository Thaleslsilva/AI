# Workflows

Definições e scripts de workflows automatizados com IA.

## O que vai aqui

- Exports de fluxos (n8n, Make/Integromat, Zapier)
- Scripts de automação (Python, Shell, Node.js)
- Pipelines de processamento de dados

## Estrutura sugerida

```
workflows/
├── n8n/          # Exports de workflows do n8n (.json)
├── make/         # Exports de cenários do Make
├── scripts/      # Scripts de automação standalone
└── pipelines/    # Pipelines de dados com IA
```
